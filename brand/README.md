# Brand files

There is no brand kit for the first release (ADR-0031). The wordmark is live text in IBM Plex Sans, there is no illustration, and `DESIGN.md` holds every visual value. Nothing in the plan waits on this folder.

If the owner supplies a brand file later, such as a favicon, a logo, or a mark, it goes here. A new ADR decides where it appears. The implementer never draws, generates, or edits a brand asset (`CLAUDE.md` rule 6).

Only add files you are allowed to self-host on a commercial site.
