# ADR-NNNN: Title as a decision

- Status: Proposed | Accepted | Superseded by ADR-NNNN
- Decision due: which day or work package
- Date proposed: YYYY-MM-DD
- Decider: the owner
- Relates to: requirement IDs, threats, other ADRs

## Context

The forces at play. What makes this a decision and not an obvious choice. Two to five sentences.

## Decision

What we will do, stated so that a reviewer can tell whether the code follows it.

## Consequences

- Gain: what gets better
- Cost: what gets worse or harder, including risks accepted

## Alternatives considered

- **Name.** Why it was not chosen.

## Evidence

Measurements, prototypes, or sources. Link to `docs/spec/09-evidence.md` entries or spike reports. Write "None needed" only when the decision does not rest on a factual claim.

## Revisit when

The observable condition that should reopen this decision.
